# 使用指南

## 快速入门

### 1. 安装依赖

首次使用前，需要安装 Go 依赖包：

```bash
# Windows
install-deps.bat

# 或使用 make
make deps
```

### 2. 运行程序

有两种方式运行程序：

**开发模式**（推荐用于测试）:
```bash
run-dev.bat
# 或
make run
```

**编译运行**:
```bash
build.bat
# 或
make build

# 然后运行
packet-capture.exe
```

### 3. 首次配置

1. **证书安装**
   - 程序首次启动时会自动生成根证书
   - 如果提示安装证书，点击确认（需要管理员权限）
   - 证书位置: `%APPDATA%\PacketCaptureTool\root-ca.crt`

2. **检查证书安装**
   ```bash
   # 打开证书管理器
   certmgr.msc
   
   # 查找 "Packet Capture Tool Root CA"
   # 应该在 "受信任的根证书颁发机构" 中
   ```

3. **配置代理端口**
   - 默认端口: 8888
   - 可在 GUI 界面修改

## 主要功能

### 启用代理

有两种方式启用系统代理：

**方式一: 使用系统托盘**
1. 在任务栏找到程序图标
2. 右键点击
3. 选择 "✅ 启用代理"

**方式二: 手动设置**
1. 打开 Windows 设置 → 网络和 Internet → 代理
2. 手动设置代理
3. 地址: `127.0.0.1`
4. 端口: `8888`（或你配置的端口）

### 捕获流量

启用代理后，所有经过的 HTTP/HTTPS 流量都会被捕获：

1. 打开浏览器
2. 访问任意网站
3. 在 GUI 的请求列表中查看捕获的流量

### 搜索和过滤

**基本搜索**:
在搜索框输入关键词即可实时过滤请求。

**搜索范围**:
- URL 路径
- 主机名
- 请求方法
- 请求头和响应头
- 请求体和响应体

**搜索示例**:

```
# 搜索所有 API 请求
api

# 搜索特定域名
github.com

# 搜索 POST 请求
POST

# 搜索特定状态码
404

# 搜索包含特定内容的请求
user_id
```

### 查看请求详情

在请求列表中点击任意请求，可以查看：
- 完整的 URL
- 请求方法
- 状态码
- 请求头和响应头
- 请求体和响应体
- 请求时长

### 清空请求历史

点击 "清空请求" 按钮可以清除所有捕获的请求记录。

### 禁用代理

使用完毕后，请记得禁用代理：

**方式一: 使用系统托盘**
1. 右键点击托盘图标
2. 选择 "❌ 禁用代理"

**方式二: 手动关闭**
1. Windows 设置 → 代理
2. 关闭手动代理设置

## 高级功能

### HTTPS 解密

默认情况下，HTTPS 解密是启用的。如果要禁用：

1. 在 GUI 界面取消勾选 "启用 HTTPS 解密"
2. 禁用后，HTTPS 请求将直接透传，不会被解密

**注意**: 禁用 HTTPS 解密后，无法查看 HTTPS 请求的详细内容。

### 修改代理端口

如果 8888 端口被占用：

1. 在 GUI 的 "代理端口" 输入框输入新端口（如 8889）
2. 程序会自动重启代理服务器
3. 记得更新系统代理设置中的端口号

### 重新安装证书

如果证书出现问题：

1. 点击 "重新安装证书" 按钮
2. 在 UAC 提示中点击 "是"
3. 等待安装完成

### 查看证书指纹

证书指纹显示在程序启动日志中，可用于验证证书的真实性。

## 浏览器配置

### Chrome / Edge

这些浏览器会自动使用系统代理设置，无需额外配置。

### Firefox

Firefox 使用独立的代理设置：

1. 打开设置 → 常规 → 网络设置
2. 选择 "手动代理配置"
3. HTTP 代理: `127.0.0.1`，端口: `8888`
4. 勾选 "也将此代理用于 HTTPS"
5. 点击 "确定"

### 移动设备

如果要抓取移动设备的流量：

1. 确保移动设备和电脑在同一网络
2. 修改程序监听地址（需要修改代码，改为 `0.0.0.0`）
3. 在移动设备的 WiFi 设置中配置代理
4. 代理地址: 电脑的 IP 地址
5. 端口: 8888
6. 在移动设备上安装根证书

**警告**: 监听 `0.0.0.0` 会将代理暴露到网络中，存在安全风险！

## 最佳实践

### 1. 及时禁用代理

使用完毕后，记得禁用代理，否则可能影响正常网络访问。

### 2. 定期清空请求

如果捕获了大量请求，定期清空可以释放内存。

### 3. 使用搜索功能

不要在大量请求中手动查找，使用搜索功能更高效。

### 4. 备份重要数据

如果需要保存某些请求数据，建议复制到外部文件。

### 5. 仅在必要时使用

抓包工具会降低网络性能，仅在需要调试时使用。

## 性能调优

### 内存使用

程序默认在内存中保存最新的 10000 条请求。如果需要调整：

修改 `internal/storage/storage.go`:
```go
// 修改这个值
if len(s.requests) > 10000 {
    s.requests = s.requests[len(s.requests)-10000:]
}
```

### 过滤无关流量

使用搜索功能过滤掉无关的请求，减少界面刷新压力。

## 故障排除

### 问题 1: 证书安装失败

**症状**: 提示证书安装失败

**解决方案**:
```bash
# 以管理员身份运行命令提示符
cd %APPDATA%\PacketCaptureTool
certutil -addstore Root root-ca.crt
```

### 问题 2: 无法捕获 HTTPS 流量

**可能原因**:
1. 证书未安装
2. HTTPS 解密未启用
3. 应用程序不使用系统代理

**解决方案**:
1. 检查证书是否在系统信任存储中
2. 确认 HTTPS 解密开关已启用
3. 某些应用（如 Electron 应用）可能需要额外配置

### 问题 3: 端口被占用

**症状**: 提示端口被占用，无法启动代理

**解决方案**:
```bash
# 查找占用端口的程序
netstat -ano | findstr :8888

# 修改代理端口
# 在 GUI 中输入新的端口号
```

### 问题 4: 系统代理设置失效

**症状**: 启用代理后，浏览器仍然不走代理

**解决方案**:
```bash
# 手动检查注册表
reg query "HKCU\Software\Microsoft\Windows\CurrentVersion\Internet Settings" /v ProxyEnable
reg query "HKCU\Software\Microsoft\Windows\CurrentVersion\Internet Settings" /v ProxyServer

# 如果值不正确，手动设置
# 在 Windows 设置中配置代理
```

### 问题 5: 程序崩溃或卡死

**解决方案**:
1. 查看日志输出
2. 重启程序
3. 清空请求历史
4. 如果问题持续，请提交 Issue

## 卸载

如果需要卸载程序：

1. **删除根证书**
   ```bash
   # 打开证书管理器
   certmgr.msc
   
   # 找到 "Packet Capture Tool Root CA"
   # 右键 → 删除
   ```

2. **删除配置文件**
   ```bash
   # 删除数据目录
   rd /s /q "%APPDATA%\PacketCaptureTool"
   ```

3. **删除程序文件**
   - 删除 `packet-capture.exe`
   - 删除相关脚本和文档
