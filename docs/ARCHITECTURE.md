# 系统架构设计文档

## 概述

Packet Capture Tool 是一个轻量级的本地网络抓包工具，采用模块化设计，使用 Golang 实现。

## 核心模块

### 1. Config (配置管理)

**职责**:
- 管理应用程序配置
- 持久化配置到 JSON 文件
- 提供线程安全的配置访问

**关键功能**:
- `LoadOrCreate()`: 加载或创建配置文件
- `Save()`: 保存配置
- `GetProxyPort()`, `SetProxyPort()`: 代理端口管理
- `GetHTTPSDecrypt()`, `SetHTTPSDecrypt()`: HTTPS 解密开关

### 2. Cert Manager (证书管理)

**职责**:
- 生成和管理 CA 根证书
- 动态签发主机证书（MITM）
- 安装证书到系统信任存储

**关键功能**:
- `NewManager()`: 初始化证书管理器
- `InstallRootCert()`: 安装根证书到 Windows
- `GenerateCertForHost()`: 为特定主机生成证书
- `GetTLSConfig()`: 获取 TLS 配置

**证书缓存**:
- 使用 `map[string]*tls.Certificate` 缓存已生成的证书
- 避免重复生成，提高性能

### 3. Storage (数据存储)

**职责**:
- 存储捕获的请求和响应
- 提供搜索和过滤功能
- 管理内存使用

**数据结构**:
```go
type CapturedRequest struct {
    ID              int64
    Timestamp       time.Time
    Method          string
    URL             string
    Host            string
    Path            string
    Protocol        string
    StatusCode      int
    RequestHeaders  map[string][]string
    RequestBody     []byte
    ResponseHeaders map[string][]string
    ResponseBody    []byte
    Duration        time.Duration
}
```

**关键功能**:
- `Add()`: 添加请求记录
- `GetAll()`: 获取所有记录
- `Search()`: 搜索匹配的记录
- `Clear()`: 清空记录

### 4. Proxy Server (代理服务器)

**职责**:
- 监听本地端口
- 拦截和转发 HTTP/HTTPS 请求
- 捕获请求和响应数据

**工作流程**:

#### HTTP 请求处理
```
客户端 → Proxy → 目标服务器
       ↓
    Storage (记录)
```

#### HTTPS 请求处理 (MITM)
```
1. 客户端发送 CONNECT 请求
2. Proxy 返回 200 Connection Established
3. Proxy 使用动态签发的证书进行 TLS 握手
4. 解密客户端请求
5. 建立到目标服务器的 TLS 连接
6. 转发请求并捕获响应
7. 加密响应发送回客户端
```

### 5. GUI (图形界面)

**职责**:
- 提供用户友好的界面
- 显示捕获的请求列表
- 提供搜索和配置功能

**组件**:
- 配置区域: 端口设置、HTTPS 开关、证书管理
- 搜索区域: 关键词搜索输入框
- 请求列表: 表格显示捕获的请求
- 状态栏: 显示请求统计信息

### 6. Systray Manager (系统托盘)

**职责**:
- 提供系统托盘图标和菜单
- 一键启用/禁用系统代理
- 快速访问常用功能

**系统代理设置**:
- 使用 Windows Registry API
- 修改 `Internet Settings` 注册表项
- 设置 `ProxyEnable` 和 `ProxyServer`

### 7. App (应用控制器)

**职责**:
- 协调各个模块
- 处理模块间通信
- 管理应用生命周期

**初始化流程**:
```
1. 加载配置
2. 初始化证书管理器
3. 创建存储实例
4. 启动代理服务器
5. 初始化 GUI
6. 启动系统托盘
7. 进入事件循环
```

## 数据流

### 请求捕获流程

```
1. 客户端发起请求
   ↓
2. 系统代理转发到 Proxy (127.0.0.1:8888)
   ↓
3. Proxy 解析请求
   ├─ HTTP: 直接处理
   └─ HTTPS: MITM 解密
   ↓
4. 读取请求体
   ↓
5. 转发到目标服务器
   ↓
6. 接收响应
   ↓
7. 读取响应体
   ↓
8. 存储到 Storage
   ↓
9. 返回响应给客户端
   ↓
10. GUI 定期刷新显示
```

### 搜索过滤流程

```
1. 用户输入关键词
   ↓
2. GUI 调用 Storage.Search()
   ↓
3. 遍历所有请求记录
   ↓
4. 匹配以下字段:
   - URL
   - Host
   - Path
   - Method
   - Headers
   - Body
   ↓
5. 返回匹配的记录
   ↓
6. GUI 更新显示
```

## 并发模型

### 线程安全
- **Config**: 使用 `sync.RWMutex` 保护配置读写
- **Storage**: 使用 `sync.RWMutex` 保护请求列表
- **Cert Manager**: 使用 `sync.RWMutex` 保护证书缓存

### Goroutine 使用
- Proxy Server: 每个请求在独立的 goroutine 中处理
- GUI Refresh: 定时器 goroutine 定期刷新界面
- Systray: 独立 goroutine 处理系统托盘事件

## 性能优化

### 内存管理
- 限制内存中的请求数量（最多 10000 条）
- 超出限制时，删除最旧的记录

### 证书缓存
- 缓存已生成的主机证书
- 避免重复的证书生成操作

### 搜索优化
- 大小写不敏感搜索
- 使用 `strings.Contains()` 进行快速匹配

## 安全考虑

### 本地限制
- 代理仅监听 127.0.0.1，不暴露到外网
- 防止被远程访问

### 证书管理
- 根证书仅用于本地 MITM
- 私钥文件权限控制
- 提供证书指纹验证

### 用户权限
- 普通权限运行
- 仅证书安装需要管理员权限（通过 UAC 提升）
